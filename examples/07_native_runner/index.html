Example 7: Native SDL2 Runner Desktop / Non-Web

This example demonstrates running the exact same compiled WASM shader binaries (such as gradient.wasm, interactive/main.wasm, physics/main.wasm or raytrace.wasm) inside a native desktop window using SDL2 in C.

How it Works

  • Initializes an SDL2 window, renderer, and streaming RGBA texture.
  • Loads the WASM shader via wash.h (using an embedded engine like Wasm3).
  • Main event loop reads mouse position, click states, and elapsed time (SDL_GetTicks) and writes them to the WASM memory buffer at the exact offsets expected by the shaders.
  • Calls _start(heap_base) every frame.
  • Streams the pixel buffer directly to SDL_UpdateTexture and renders at native monitor refresh rates with live FPS calculation.

Compilation & Running

# 1. Compile the SDL2 runner
cd examples/07_native_runner
make wasm3

# 2. Run any existing Wash WASM shader in a native window:
./wash_sdl ../04_interactive/main.wasm 800 600
./wash_sdl ../03_benchmark/raytrace.wasm 640 480
./wash_sdl ../05_physics/main.wasm 800 600
./wash_sdl ../01_gradient/gradient.wasm 800 600
