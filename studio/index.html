1. What is Wash?

Wash is a minimalist WebAssembly compute engine and shader pipeline. It enables writing pure C functions compiled to WebAssembly that operate on shared linear memory with zero serialization overhead and seamless multi-threading.

2. JavaScript API Reference

Function Description
wash_memory(size, heapBase = 65536) Creates a shared WebAssembly linear memory buffer. Provides .u8, .rawU8(offset, size), and .buffer views.
wash_load(urlOrBytes, sharedMemory) Instantiates a WebAssembly shader and attaches the shared memory buffer.
wash_run(shader, ...args) Executes the shader's _start function with arbitrary typed arguments (numbers, booleans, pointers, strings).
wash_worker() Spawns an isolated background Web Worker with .run(shader, ...args), .runSlice(...), and .destroy().

3. Writing C Shaders

Every C shader exports a _start function with arbitrary arguments:

#include <stdint.h>

__attribute__((export_name("_start")))
uint32_t _start(uint8_t* pixels, uint32_t width, uint32_t height, float time) {
    for (uint32_t y = 0; y < height; ++y) {
        for (uint32_t x = 0; x < width; ++x) {
            uint32_t off = (y * width + x) * 4;
            pixels[off + 0] = (uint8_t)((x * 255) / width); // R
            pixels[off + 1] = (uint8_t)((y * 255) / height); // G
            pixels[off + 2] = 160;                            // B
            pixels[off + 3] = 255;                            // A
        }
    }
    return 1;
}

4. Fast Portable Math Functions

For standalone WebAssembly without external libc dependencies, use fast polynomial & Newton approximations:

// Fast square root (Newton's method)
static float sqrt_fast(float x) {
    if (x <= 0.0f) return 0.0f;
    float g = x * 0.5f;
    for (int i = 0; i < 5; ++i) g = 0.5f * (g + x / g);
    return g;
}

// Fast sine & cosine (Bhaskara polynomial)
static float sin_fast(float x) {
    float k = (int)(x * 0.1591549f);
    x = x - k * 6.2831853f;
    if (x < -3.14159265f) x += 6.2831853f;
    if (x >  3.14159265f) x -= 6.2831853f;
    float a = x < 0 ? -x : x;
    return (16.0f * x * (3.14159265f - a)) / (49.348022f - 4.0f * a * (3.14159265f - a));
}
static float cos_fast(float x) { return sin_fast(x + 1.5707963f); }

5. Multi-Shader Shared Memory Pipeline

Multiple shaders can read/write the same shared memory buffer consecutively:

// 1. Single shared memory allocated once
const mem = wash_memory(PARTICLE_BYTES + PIXEL_BYTES);

// 2. Both shaders bound to the same memory
const simShader    = await wash_load(shaders["simulate.wasm"], mem);
const renderShader = await wash_load(shaders["render.wasm"], mem);

// 3. Sequential pipeline executed every frame
wash_run(simShader, particlesPtr, width, height, numParticles);
wash_run(renderShader, particlesPtr, pixelsPtr, width, height);
